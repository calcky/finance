# 宏观数据与更新

本专题收录可追溯的真实宏观时间序列，与基础课程中的教学假设分开。从 GDP 总量出发，再观察物价、货币、利率、经济活动、家庭收入和对外收支。

先打开[宏观经济总览](overview.md)：按六个观察维度查看最新值、前次观测与历史范围，再沿传导图和组合阅读示例进入各专题。

“每日检查”不等于所有指标实时更新。WDI 的年度数据可能晚于国家统计局季度快报，月度接口也可能晚于新闻发布页；看各指标的最新统计期，不以网页构建日期判断新旧。即期成交汇率和日内行情尚未接入。不同来源保持独立口径，不把季度快报补进 WDI 年度历史序列。

## 保存位置

小型、允许公开再分发的数据集保存在仓库根目录 `data/`，采用 UTF-8 CSV。数据说明和分析放在文档中；构建出的 HTML 不入库。

每个数据集提供 CSV 与机器可读元数据，说明包含序列定义、单位、频率、口径变化、缺失值约定和来源参数。十四个中国宏观专题和一个美国利率专题保存在 `data/macro/<topic>.csv` 和 `<topic>.metadata.json`；共 64 张交互图，阅读说明与图表在本节对应页面。

已提供的 GDP 数据为 `data/gdp.csv`、`data/gdp.md` 和机器可读的 `data/gdp.metadata.json`；图表与页面由该快照生成。

大型原始文件或不允许再分发的数据只记录来源与获取办法。公开网页上的数据不自动等于可以镜像发布的数据。

## 每条观测至少记录

| 字段 | 含义 | 约定 |
|---|---|---|
| `series_id` | 指标序列标识 | 英文稳定名称，不混合不同口径 |
| `country` | 国家或地区 | 跨国数据必须包含，例如 `CHN`、`USA` |
| `period` | 统计期间或报价时点 | 年度 `YYYY`、月度 `YYYY-MM`、季度 `YYYY-Qn`、日度 `YYYY-MM-DD`；日内报价另含时间与时区 |
| `value` | 数值 | 纯数字；缺失留空，不能用 0 代替 |
| `unit` | 单位 | 同一序列保持一致，例如 `CNY_100m`、`percent` |
| `published_at` | 来源发布时间 | 已知日期或带时区时间；未知留空，不用抓取时间冒充 |
| `retrieved_at` | 获取时间 | 带时区的 ISO 8601 时间 |
| `source_url` | 对应发布页或数据文件 | 尽量指向具体发布物，而非机构首页 |
| `note` | 口径、修订或异常说明 | 可为空；需要解释的变化必须写明 |

一份 CSV 默认保存每个 `series_id + country + period` 的最新可得版本，组合键不得重复。Git 提交记录和数据集说明保留本项目开始采集后的修订过程；如果研究需要同时比较初值与修订值，应明确增加版本维度，不能悄悄混入重复行。

## 一次更新的流程

1. 确认来源已发布新数据，核对使用与再分发条件。
2. 核对统计期间、单位、季调、同比 / 环比和新旧口径。
3. 更新 CSV，补齐发布时间、获取时间与具体来源。
4. 检查重复键、缺失值、异常变化，以及来源是否修订了历史值。
5. 在同名说明中记录新增期间、修订范围和原因；涉及口径变化时同步修订指标说明。
6. 构建文档并检查链接，审核变更后提交与推送。

数据未发布、来源暂时不可用或校验失败时，保留上一次有效数据并明确说明缺口，不用估计值填成官方值。

## 更新频率如何确定

月度宏观指标在正式发布后更新，GDP 跟随季度及修订发布，政策利率跟随政策公告，行情跟随选定产品的采样频率。网站构建时间与数据更新时间不同，页面变新不意味着所有指标都变新。

年度 GDP 与十五个宏观专题的统一同步任务设为每天北京时间 06:17 检查，也可手动触发。GitHub 定时任务可能延迟或跳过，公开仓库长期不活跃时还可能暂停，不能视为准点服务。最近检查结果以 [Actions 记录](https://github.com/calcky/finance/actions/workflows/update-gdp.yml) 为准。

日常更新保留全历史，每月首次定时任务另做全量回溯，手动触发时也可选择 `backfill`。[历史覆盖与来源核验](history-coverage.md)说明实际起点、口径断点与仍存在的缺口。

观测和定义无变化的日常检查不生成提交；快照获取时间因此可能早于最近检查时间，单纯查询日期变化不算新数据。接口异常、查询范围内已知值消失或校验失败时，任务报错、保留上次快照。历史合法修订会重新生成表格和图表。

采集任务负责下载、校验、生成和提交；Read the Docs 使用已入库的快照构建网站。文档构建本身不访问数据接口，以便离线复现，也避免来源故障导致知识文档无法发布。
