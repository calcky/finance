# 指标目录

本页记录指标的含义与查询入口，**不提供当前读数或实时行情**。频率指常见统计或发布频率，具体时间以发布机构日历为准。

已接入的真实序列请看 [GDP 数据专题](../data/gdp.md)：中国年度 GDP、实际增速、人均 GDP 与中美美元 GDP 对照。该专题采用世界银行 WDI 年度口径，不替代国家统计局最新季度发布。

## 货币、信用与经济活动

| 指标 | 常见展示单位 | 频率 | 主要来源 | 解读重点 |
|---|---|---|---|---|
| M0、M1、M2 | 亿元 / 万亿元；同比 % | 月度 | [中国人民银行](https://www.pbc.gov.cn/diaochatongjisi/116219/116319/index.html) | 存量与增速分开记录；M1 注意 2025 年启用的新口径 |
| 社融存量、增量 | 亿元 / 万亿元；存量同比 % | 月度 | [中国人民银行](https://www.pbc.gov.cn/) | 增量不是存量；拆分政府债券、贷款等来源 |
| GDP | 亿元；实际同比 / 环比 % | 季度、年度 | [国家统计局](https://www.stats.gov.cn/) | 区分当季、累计、名义金额与实际增速 |
| CPI、核心 CPI | 指数；同比 / 环比 % | 月度 | [国家统计局](https://www.stats.gov.cn/) | 明确基期；涨幅回落不等于价格下降 |
| PPI | 指数；同比 / 环比 % | 月度 | [国家统计局](https://www.stats.gov.cn/) | 工业出厂价格，与消费价格覆盖范围不同 |
| PMI | 扩散指数，0—100 | 月度 | [国家统计局](https://www.stats.gov.cn/) | 区分制造业、非制造业与分项；50 是荣枯分界 |

原理见[货币与信用](../money-and-credit.md)、[增长与通胀](../growth-and-inflation.md)。

## 利率与政策

| 指标 | 单位 | 频率 | 主要来源 | 解读重点 |
|---|---|---|---|---|
| 7 天期逆回购操作利率 | 年化 % | 按操作公告 | [中国人民银行](https://www.pbc.gov.cn/) | 记录操作期限、公告与生效时间 |
| LPR | 年化 % | 月度报价 | [中国货币网](https://www.chinamoney.com.cn/) | 1 年期、5 年期以上分别记录 |
| 联邦基金利率目标区间 | 年化 %，上下限 | 按政策决定 | [美联储](https://www.federalreserve.gov/monetarypolicy/openmarket.htm) | 上下限不是有效联邦基金利率的实际成交读数 |
| 国债收益率 | 年化 % | 通常交易日 | 对应市场官方或授权数据源 | 必须注明国家、期限与收益率类型，不混用不同曲线 |

利率变动通常用基点表示，`100 bp = 1 个百分点`。解释见[利率与货币政策](../interest-rates.md)。

## 汇率与黄金

| 指标 | 单位 / 口径 | 频率 | 主要来源 | 解读重点 |
|---|---|---|---|---|
| USD/CNY 中间价 | 人民币 / 美元 | 发布日 | [中国货币网](https://www.chinamoney.com.cn/) | 中间价与在岸即期、银行结售汇价分开 |
| USD/CNY、USD/CNH 即期 | 人民币 / 美元 | 依报价源与采样时间 | 选定的市场数据提供方 | 注明在岸 / 离岸、买卖 / 中间报价与时区 |
| ICE 美元指数 DXY | 指数点 | 市场报价 | [ICE](https://www.ice.com/products/194/US-Dollar-Index-Futures) | 区分指数与期货合约；数据获取及再分发遵守授权 |
| CFETS 人民币汇率指数 | 指数点 | 依官方发布安排 | [中国货币网](https://www.chinamoney.com.cn/) | 留意篮子权重调整，不等同于美元兑人民币 |
| 国际黄金基准 / 现货 / 期货 | 美元 / 金衡盎司 | 依具体产品 | [世界黄金协会](https://www.gold.org/)及相应基准或交易机构 | 必须指定产品、定价时点与期限，不能合成一条无口径的“金价” |
| 上海黄金交易所合约价格 | 人民币 / 克 | 交易日 | [上海黄金交易所](https://www.sge.com.cn/) | 注明合约和价格类型，不与金饰零售价混用 |

解释见[汇率、美元指数与人民币](../exchange-rates.md)和[黄金](../gold.md)。

## 新增指标前记录什么

为每条序列确定稳定的英文 `series_id`，记录定义、单位、统计范围、频率、来源、价格或增长口径。GDP 当季实际同比与 GDP 累计名义金额属于不同序列；同一指标的中间价和收盘价也不能混在一列。

来源入口不等于可直接调用的免费 API。选择采集方式时另行核实访问条件、修订机制和公开再分发许可，详见[数据与更新](../data/index.md)。
