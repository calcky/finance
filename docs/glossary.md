# 术语速查

[返回首页](index.md) · [学习路线](learning-guide.md)

这里用于读到一半时快速回查，不要求先背术语。短定义不能代替章节里的条件与例子。

| 术语 | 入门理解 | 进一步阅读 |
|---|---|---|
| 资产 / 负债 / 净资产 | 拥有的经济资源 / 债务义务 / 两者之差 | [经济与金融](foundations/economic-map.md) |
| 存量 / 流量 | 某时点余额 / 某期间发生量 | [经济与金融](foundations/economic-map.md) |
| 复利 | 收益继续投入，后续结果在新的本金基础上计算 | [收益与风险](foundations/money-time-risk.md) |
| 年化收益 | 把某期间回报转换为年度可比表达，不等于承诺 | [收益与风险](foundations/money-time-risk.md) |
| 实际收益 | 扣除价格水平变化后的购买力收益 | [收益与风险](foundations/money-time-risk.md) |
| 流动性 | 能否及时、以合理成本变现或获得可用资金，须看语境 | [个人财务底座](foundations/household-finance.md) |
| 折现 | 把未来现金流按给定回报要求折算到今天 | [收益与风险](foundations/money-time-risk.md) |
| 信用风险 | 对方未按合同履行义务的风险 | [存款与债券](investing/bonds.md) |
| 票息 / 收益率 | 合同付息规则 / 结合价格与现金流计算的回报指标 | [存款与债券](investing/bonds.md) |
| 久期 | 与债券现金流时间及利率敏感度有关的指标 | [存款与债券](investing/bonds.md) |
| 股权 / 债权 | 企业权益与剩余风险 / 合同约定的偿付请求权 | [股票](investing/stocks.md) |
| P/E / 市盈率 | 股价与每股收益的比值，需明确盈利口径 | [股票](investing/stocks.md) |
| 净值 / 价格 | 份额对应净资产 / 实际市场成交报价 | [基金](investing/funds.md) |
| 指数 / 指数基金 / ETF | 一套衡量规则 / 跟踪指数的基金 / 交易所交易基金 | [基金](investing/funds.md) |
| 分散 / 再平衡 | 降低集中暴露 / 将权重调回目标 | [投资组合](investing/portfolio.md) |
| 杠杆 | 使用借款等方式放大资产敞口，也可能放大亏损 | [投资组合](investing/portfolio.md) |
| M0 / M1 / M2 | 按统计口径划分的不同货币范围，国家和版本需明确 | [货币与信用](money-and-credit.md) |
| 社融 | 实体经济从金融体系获得资金的统计，含增量与存量 | [货币与信用](money-and-credit.md) |
| GDP | 一定时期的国内生产最终成果 | [增长与通胀](growth-and-inflation.md) |
| CPI / PPI | 消费价格 / 工业出厂价格的统计指数 | [增长与通胀](growth-and-inflation.md) |
| PMI | 企业调查形成的扩散指数，不是 GDP 增速 | [增长与通胀](growth-and-inflation.md) |
| 同比 / 环比 | 与上年同期 / 上一相邻期间比较 | [数据练习](data/reading-exercise.md) |
| 基点 bp / 百分点 | 1 bp = 0.01 个百分点，区别于相对百分比 | [利率](interest-rates.md) |
| LPR | 中国贷款市场报价利率，是重要贷款定价参考 | [利率](interest-rates.md) |
| 降准 / 降息 | 调整法定准备金比例 / 调整某种利率 | [利率](interest-rates.md) |
| CNY / CNH | 通常分别指在岸 / 离岸人民币市场报价 | [汇率](exchange-rates.md) |
| DXY / CFETS | 美元 / 人民币对相应篮子货币的指数 | [汇率](exchange-rates.md) |
| 金衡盎司 | 贵金属常用质量单位，约 31.1034768 克 | [黄金](gold.md) |

“流动性”“收益率”“美元指数”等词在不同场景可能指不同对象；不清楚时先问数据的具体名称、来源和口径。
