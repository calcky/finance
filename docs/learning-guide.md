# 学习路线：从生活中的钱到金融数据

[返回首页](index.md)

不需要经济学或投资经验。先学会解释自己的收支与风险，再认识金融产品，最后读懂宏观新闻和数据。每次只读一章，能用自己的话回答章末问题后再继续；不要求先背下所有缩写。

## 五个阶段

| 阶段 | 按顺序阅读 | 学完能做什么 |
|---|---|---|
| 1. 建立基本概念 | [经济与金融的地图](foundations/economic-map.md) → [收益、复利与风险](foundations/money-time-risk.md) → [个人财务底座](foundations/household-finance.md) | 分清收入与财富，算收益，判断钱何时要用 |
| 2. 认识产品与投资 | [存款与债券](investing/bonds.md) → [股票](investing/stocks.md) → [基金与 ETF](investing/funds.md) → [风险与投资组合](investing/portfolio.md) | 解释收益从哪里来、谁承担损失、产品里实际装了什么 |
| 3. 看懂宏观经济 | [银行与货币创造](banking-and-money-creation.md) → [货币与信用](money-and-credit.md) → [增长与通胀](growth-and-inflation.md) → [利率与政策](interest-rates.md) | 先用五张图看懂贷款、存款与结算，再把 M1、M2、社融、GDP 和政策放进同一框架 |
| 4. 理解跨市场联系 | [汇率与美元指数](exchange-rates.md) → [黄金](gold.md) | 区分美元收益与人民币收益，理解黄金的驱动因素 |
| 5. 用数据检验解释 | [综合阅读宏观数据](reading-macro-data.md) → [一次数据阅读练习](data/reading-exercise.md) | 核对口径、算同比，区分证据、推测与预测 |

一共 15 个学习单元。可以分多次完成，不必按固定天数打卡。[术语速查](glossary.md)用于回查，[指标目录](indicators/index.md)用于找定义和来源。

第三阶段之后，可沿[社融与信贷结构](credit-structure.md) → [房地产如何影响经济](property-and-economy.md)继续阅读：先分清融资渠道和借款人，再用销售、回款、建设与投资的数据检验传导机制。两篇是专题延伸，不要求先掌握复杂模型。

## 为什么不从 M2 或选基金开始

如果尚未区分存量与流量，就容易把“M2 增加”读成“每个人收入增加”；如果不知道债券是借贷关系，就难理解债券基金为何也会亏损。前两阶段为后面的指标和政策提供必要背景。

学习次序也不等于投资步骤。完成一个章节意味着更会提问，不意味着已经具备判断某只产品是否适合自己的全部信息。

## 每章怎样读

1. 先看章首的问题，联系一个熟悉的生活场景。
2. 先沿图中的箭头或账目变化复述过程，再用纸笔或计算器复算例子。
3. 阅读误区，尝试找出结论成立的条件。
4. 先独立回答自测，再看参考答案。
5. 用一句话记录“我现在能解释什么，还有什么不知道”。

所有金额和场景例子默认是教学假设。真实数据另按[数据规范](data/index.md)记录来源与日期，不能拿例子当行情。

每章至少配一张核心图。看流程图时问“箭头表示什么，成立需要哪些条件”；看数值图时先读横纵轴、单位和假设，再核对公式。特别注意：债券价格图的横轴是收益率，不是时间；M0/M1/M2 的嵌套框表示范围，不表示金额比例。

## 一条贯穿全书的线索

假设一个家庭有工资收入、存款和贷款，也准备为未来目标存钱：

- 第一阶段：算清现金流、净资产、购买力和短期资金需要。
- 第二阶段：比较存款、债券、股票和基金的权利与风险。
- 第三阶段：理解就业、物价和利率环境会怎样影响家庭与企业。
- 第四阶段：识别外币资产和黄金额外带来的汇率风险。
- 第五阶段：检查财经新闻是否有证据，避免用一个数字预测全部市场。

## 学习的边界

这套文档是入门教育，不提供个性化仓位、买卖信号或收益承诺。税务、保险与产品合同受地区和时间影响，需要核对当地规则及具体条款。衍生品定价、量化交易和复杂会计可在掌握这些基础后再学习。
