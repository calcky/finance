# 金融数据

本目录保存规模适中、按来源条款公开再分发的金融数据；知识文档里的教学示例不属于数据记录。

| 数据集 | 数据 | 说明 | 来源元数据 |
|---|---|---|---|
| GDP 年度历史序列 | [gdp.csv](gdp.csv) | [gdp.md](gdp.md) | [gdp.metadata.json](gdp.metadata.json) |
| 物价与通胀 | [CSV](macro/prices.csv) | [阅读说明](../docs/data/prices.md) | [元数据](macro/prices.metadata.json) |
| 货币与社会融资 | [CSV](macro/money-credit.csv) | [阅读说明](../docs/data/money-credit.md) | [元数据](macro/money-credit.metadata.json) |
| 利率 | [CSV](macro/rates.csv) | [阅读说明](../docs/data/rates.md) | [元数据](macro/rates.metadata.json) |
| 经济活动 | [CSV](macro/activity.csv) | [阅读说明](../docs/data/activity.md) | [元数据](macro/activity.metadata.json) |
| 就业与收入 | [CSV](macro/employment-income.csv) | [阅读说明](../docs/data/employment-income.md) | [元数据](macro/employment-income.metadata.json) |
| 贸易与汇率 | [CSV](macro/trade-fx.csv) | [阅读说明](../docs/data/trade-fx.md) | [元数据](macro/trade-fx.metadata.json) |

数据使用 CSV，口径和采集参数使用 JSON；宏观专题的可读说明放在 `docs/data/`。字段与更新流程见[数据与更新](../docs/data/index.md)。指标定义见[指标目录](../docs/indicators/index.md)。来源网页和原始文件不整站镜像；来源条款与版权归各机构，本项目许可不重新授权第三方数据。
