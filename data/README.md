# 金融数据

本目录保存规模适中、按来源条款公开再分发的金融数据；知识文档里的教学示例不属于数据记录。

| 数据集 | 数据 | 说明 | 来源元数据 |
|---|---|---|---|
| GDP 年度历史序列 | [gdp.csv](gdp.csv) | [gdp.md](gdp.md) | [gdp.metadata.json](gdp.metadata.json) |

按 `<dataset>.csv` 与 `<dataset>.md` 成对保存数据和说明，必要时附机器可读元数据。字段与更新流程见[数据与更新](../docs/data/index.md)。指标定义见[指标目录](../docs/indicators/index.md)。
